# 文件、發行歷史及通知檢視

[English](documentation-notifications.md) · [功能索引](README.md)

## 閱讀離線說明

喺工作區開啟「說明及文件」。建置會綑綁已收錄嘅文件及設計文章、分類索引同獲准本機圖片。閱讀器提供本機標題及內文搜尋、現有正則表達式建立器、標題導覽、文章連結、上一頁、下一頁同首頁。最近開啟文章及章節保存在本機，下次回訪會還原。缺少文章會明確顯示無法使用。

Markdown 由主機共用渲染器處理，原始 HTML 停用。相對連結只解析至綑綁內已收錄文章 ID 及錨點。外部 HTTPS 連結要明確點選，再以主機擁有嘅連結 ID 開啟。圖片唔會引發網絡請求；缺少或者不支援資源會顯示不可用。閱讀文件唔會開始建置或者修改專案。

## 檢視通知

頁首「通知及變更」開啟非模態檢視中心。Escape 或關閉會將焦點交回觸發控制。工作區儲存結果、建置工作終止狀態同未成功操作回覆會建立固定主機通知，唔記錄請求內容、專案路徑、憑證或者原始錯誤。報告失敗唔會改寫操作結果。

通知及檢視決定沿用本機只增不改儲存。標為已讀、未讀、已解決或者略過都保留原事件；未讀會放回待處理流程。每頁載入 100 筆，畫面分清已載入數量同總歷史。文字或隔離工作執行緒正則搜尋、狀態及日期範圍會一併篩選已載入記錄，篩選設定本機保留。

核取方塊支援鍵盤及 Shift 點選範圍。全選及反選只作用於已載入匹配。批次動作前先顯示所選標題及時間，每個請求最多 100 個 ID。部分寫入會如實報告，可重新載入檢查。複製及 Markdown 匯出使用已選匹配；冇選擇時使用全部已載入匹配，保留當前範圍同搜尋。呢個介面唔提供永久刪除。

## 閱讀發行歷史

變更紀錄使用 `src/main/documentation/releases.json` 中已擷取發行清單，每筆保留實際版本、標題、發佈時間、說明、發行網址及已解析來源提交。畫面顯示快照時間，唔會推斷之後新發行。缺少說明會明確指出，原文唔會改寫成虛構修正或者翻譯後嘅事實。

發行說明使用同一個不執行內容嘅主機 Markdown 渲染器。來源提交同發行頁有明確主機連結操作。日期、文字及正則篩選可合用；選擇、複製及匯出保留來源參照。產生新文件包前必須確定每個擷取來源提交存在。取得發行資料同普通建置分開，新發行後要明確更新快照。

## 檢視連線狀態

連線狀態只讀取現有有型別 Status Hub 投影：固定狀態同原因代碼、最近嘗試、最近成功送達及已認證送達布林值。缺少用戶端或登記就顯示不可用。更新經可信主機服務執行；顯示層唔會收到登記操作、地址、憑證、原始服務錯誤或者收件匣內容。開啟畫面唔證明已認證送達。

## 待驗收事項

本輪只實作並準備建置，測試、靜態分析、實際操作、無障礙評估及畫面擷取延後。日期範圍控制有月份及年份跳轉、端點、包含首尾範圍、今天、7 日及 30 日預設，以及 ISO 或 M/D/YYYY 輸入；未完成輸入保持可見並顯示行內訊息。

自有介面句子使用共用語言及獨立幽默控制，已發佈說明同記錄通知保持原文。永久刪除刻意不提供。通知歷史涵蓋工作區儲存、建置終止及未成功操作；下載進度仍在既有更新介面。發行清單係有日期快照，唔係即時網絡。離線完整性只限獲准來源清單，唔會虛構未取得嘅外部 wiki 歷史。以上都係待驗收，唔係已通過。
