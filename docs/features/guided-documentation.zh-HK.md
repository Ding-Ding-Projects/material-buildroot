# 新手文件指南

[English](guided-documentation.md) · [文章目錄](README.md)

首頁先提供四步入門指南：問你想學乜、比較 WSL 2 同 Docker Linux 容器、解釋目前 ISO 欄位，再指出一個具體閱讀下一步。原有由來源到映像、配方、疑難排解同安全指南都留喺下面。完整文章沿用既有文章顯示器，冇另起一套。

## 選擇同預設

首次到訪預設由基本概念開始。WSL 2 只係初始說明，唔代表已偵測或已安裝。應優先選用項目已配置好嘅合適環境。兩張環境卡都列出先決條件。

ISO 例子講解 x86_64 BIOS 目標、兩個並行工作，同 `images/rootfs.iso9660` 輸出。確切開機載入器同映像設定以已安裝程式目前計劃為準。此設定唔支援 UEFI 或混合 USB。獨立輸出目錄可以保護舊結果，避免正常增量製作更新原有產物。

每次選擇都會改變相關說明或最後下一步。映像欄位按鈕會顯示說明、例子同完整欄位文章連結。Back 同 Next 保留選擇。指南沿用語言偏好提供英文、粵語同雙語內容，使用正式 Material 按鈕、配合可讀標籤嘅裝飾符號、響應式卡片同減少動態效果樣式。切換步驟會聚焦標題，改變選擇會將焦點還原到該選項。

## 本機進度同私隱

`mb-beginner-guide-v1` 只儲存版本、有界限嘅步驟索引、列舉式目標／環境／欄位選擇，同閱讀標記。載入時會移除未知欄位。狀態唔包含路徑、憑證、任意文字、桌面存取或可執行指令。重設只取代此入門指南狀態，保留其他學習進度同已儲存參考。瀏覽器儲存無法使用時，會清楚提示重新載入後資料唔會保留。

每個活動都只係瀏覽器學習示例。控制項唔會執行 Buildroot、檢查電腦、套用項目配置或將真實建置標記成功。閱讀標記只記錄閱讀。WSL 同 Docker 嘅 `olddefconfig`／`show-info` 檢查已有獨立驗證，但完整 ISO 製作同啟動要各自有證據，唔可以由小型檢查推斷。現有[ISO 啟動記錄](../evidence/iso-boot/README.md)只適用於該指定產物同消費端組合。

## 驗證

`node website/test-beginner-guide.mjs` 檢查格式錯誤嘅持久狀態、無效列舉值、越界步驟、移除無關欄位同雙語欄位清單。正式文件檢查器亦會列出每個環境、映像欄位同最終目標文章目的地，轉成 `.html`，再要求同產生嘅文件清單完全一致。目的地缺少或唔匹配會令驗證失敗。

以上只係來源層面證據。整合文件建置必須產生所連結嘅 ISO 文章並驗證路由。真正鍵盤操作、選擇、Back/Next、重新載入後保留、重設隔離、語言切換、儲存不可用同 320 像素畫面，都需要喺建成瀏覽器畫面驗證先算完成。畫面擷取同部署交付證據屬於該次整合執行。
