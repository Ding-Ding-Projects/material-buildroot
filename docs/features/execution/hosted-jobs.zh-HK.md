# 託管 Buildroot 工作控制

[English](hosted-jobs.md) · [執行索引](README.md)

執行 workflow 面板喺使用者核取明確同意後，排隊一份已發佈及獲准 workflow。只接受公開來源同執行來源，以及固定 `ubuntu-24.04` 託管 runner。來源提交、目標、defconfig 及並行數固定喺 workflow，派送只提供新操作 UUID。

本機日誌喺派送前寫入。不確定回覆維持 `dispatch-unconfirmed`，只可觀察或者重新連接，唔自動再派送。執行探索匹配操作 UUID、精確來源、workflow 路徑及 workflow 提交，拒絕 rerun 嘗試，唔偷偷接管。使用者明確輪詢，一次最多五頁。queued、pending、waiting、in-progress 同 completed 只反映服務觀察。取消請求唔代表終止，下次觀察要確認最終結論。

重啟歷史只存資料，唔存憑證或者權限。選返同一目的地，續期目前帳戶授權，再重新連接並核對已儲存執行綁定。身份改變、撤銷授權或者服務無法到達都明確錯誤。

## 下載及解壓

只接受成功綁定執行、未過期、API 提供 SHA-256 嘅 `buildroot-output`。下載由可信 GitHub CLI、原生目錄選擇器及全新輸出子目錄處理，唔接受顯示層路徑。壓縮下載串流至獨佔部分檔案，最多 1,107,296,256 位元組、十分鐘。可信 CLI 核對預期大小及 SHA-256 先發佈壓縮檔。取消只中止自己傳輸或解壓，更大輸出不支援。

讀 ZIP 清單前摘要及精確長度必須相符。`manifest.json` 綁定操作 UUID、workflow 提交及來源提交，每個普通檔案要有精確長度及 SHA-256。解壓拒絕路徑穿越、符號連結、重名、不支援方法及 ZIP64；最多 1,000 個直接 `images/<basename>`、合計 1 GiB，加最多 1 MiB 清單。唔覆寫既有檔案或執行解壓內容。摘要只證明同服務資料一致，唔證明發行者身份或者韌體安全。

下載 ZIP 直接包含 `manifest.json` 同 `images/<basename>`，唔包多層壓縮檔。新資料夾先有 `output-status.json` 未完成收據，只有完整摘要、清單及解壓成功先變 `verified`。非空部分下載、被中斷或拒絕解壓都保留診斷，唔當已驗證輸出。原有專案及輸出樹不變。

## 驗收狀態

限範圍交付只完成來源，冇派送託管執行、建立外部來源、測試、實際檢視或者畫面擷取。派送、取消、重啟復原、下載及解壓仍未驗收。
