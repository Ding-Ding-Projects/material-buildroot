# 排程語言及外觀偏好

[English](scheduled-preferences.md) · [功能索引](README.md)

設定排程編輯本機日期、時間、星期及優先規則，明確儲存先按目前修訂驗整份文件。有效值畫面標活躍值，保留使用者基底，過期回基底。

## 編輯及復原

未存修改保護導覽及關窗，儲存中不能捨棄或關。衝突保留草稿並要檢視儲存狀態。儲存/移除結果未知要先讀回，來源移除亦要再選及確認。

明確捨棄先將已驗本機草稿寫獨立有界歷史。還原只載入編輯器唔啟用。混合文件只有外部記錄未改時先獨立保留本機編輯，還原合目前外部記錄、錨定最新修訂並拒絕 ID 衝突或超限，仍要手動儲存。參閱[草稿儲存及權限](../security/schedule-draft-recovery.md)。

## 受保護來源登記

有明確登記 HTTPS/Home Assistant origin 列表、儲存及移除。設定保留同 origin 選擇，私人地址要刻意揀，並說明外部規則可能更新時即套用。憑證只係臨時輸入，之後清除，安全讀回只有 metadata。共用限制移除表格、阻修改，但保留允許資料檢視。
