# 工作區歷史及限範圍匯出

[English](workspace-history.md) · [功能索引](README.md)

設定內工作區備份記錄已套用計劃、筆記、主題及設定進度，唔備份來源目錄、建置輸出或受保護憑證。原生專案目錄、選項及本機排程有下述獨立歷史流程。

## 修訂及復原

成功修改會喺程式資料旁記錄完整前後狀態，以獨立 bare Git 來源儲存不可變修訂及只增不改提交。唔喺使用者專案建立工作目錄，唔加入遠端、推送、同步、改寫或者自動清理歷史。主機要經支援執行檔搜尋取得 Git，缺少或者歷史儲存不可用會顯示警告，同時保留已成功工作區儲存。

每頁載入 25 筆，可用 UTC 日期範圍、文字同隔離工作執行緒正則搜尋已載入頁面。動作篩選由已載入記錄產生並顯示數量。錨定表達式工作台同步查詢，工作執行緒限制防止阻塞；範圍同匹配數可見。支援同目前工作區比較、追加標籤及還原。比較顯示計劃新增、移除、變更，以及偏好同設定進度。具名快照繼續可用，兩種還原都建立新修訂，舊歷史保留，唔匯入憑證或者改語言。

原有文件仍第 1 版，唔重設或者破壞遷移。完整狀態擷取之前嘅活動唔會被重建成可還原修訂；完整歷史從新實作首次儲存開始。未變更值唔新增修訂，未提交顯示層草稿唔包含喺儲存快照或匯出。

## 明確快取保留

可選保留最近 25、100 或 500 個快取修訂，檢視確認後先移除重複快取。移除前同不可變 Git 記錄逐位元組核對，所有提交同完整內容仍保留，冇快取嘅修訂可直接從 Git 還原。呢個唔係不可逆歷史刪除，亦唔保證回收全部歷史空間。唔自動清理，途中中斷唔刪除對應歷史。

## 匯出範圍及私隱

主機驗證範圍及目前修訂。全部為 UTF-8 JSON、LF 換行及明確有版本格式。

| 範圍 | 內容及限制 |
| --- | --- |
| 目前工作區 | 原有第 1 版格式，包括已套用計劃、主題及設定狀態，可經完整驗證匯入 |
| 所選已儲存計劃 | 只有所選 ID，可全選及反選，標示來源修訂及排除；報告格式唔可工作區匯入 |
| 完整已記錄活動 | 所有分頁活動，包括記憶體最新 100 筆以前記錄；只係報告，唔係還原文件 |
| 全部完整修訂 | 完整已保留狀態及標籤，最多 32 MiB，超出整份失敗，唔截斷；唔可工作區匯入 |
| 最近 25 個匹配已載入修訂 | 明確有界頁面匯出，含選中身份及完整狀態；大型歷史要載入舊頁再明確匯出，唔係無限或自動串流 |

投影唔讀憑證庫、個人用詞、來源檔案資料、自訂圖片、外部服務登記、專案路徑或者建置輸出。計劃名稱、筆記同自填標籤按範圍包含，匯出前要自行檢視敏感內容；程式唔假裝可以猜出手動輸入嘅秘密。

## 原生專案記錄

目錄喺接入及還原時記錄前後文件，每專案選項亦記錄執行環境及外部樹選擇，各用獨立本機 bare Git 歷史，保留 v1 至 v2 遷移、穩定 ID 同現況。備份面板可選目錄或者某專案選項，顯示安全資料，匯出唔含本機路徑，還原要明確確認。

還原只新增原生修訂，唔改來源內容或者授予選擇器能力，要正常重新選擇受影響專案。已執行操作保留原有授權狀態。根目錄、來源、輸出及外部樹路徑只留喺本機復原記錄，唔喺普通歷史匯出。

## 排程偏好

本機有效規則快照保存在既有 SQLite 文件/歷史交易嘅保留內部鍵，唔加第二本日誌，沿用原 schema 同收據。外部規則、登記及憑證排除。舊收據可能冇完整快照，會標示不能復原。

排程面板可載入有效本機快照成草稿，合併會保留目前外部規則同相對次序；只有明確「儲存排程」先成新修訂。捨棄草稿歷史沿用本機儲存、界限同還原。兩類歷史只匯出最近已載入頁面，最多 25 筆有效或 20 筆捨棄，包含可用本機快照並明示缺少。共用限制模式下停用，主機再次授權；唔讀或匯出憑證、外部規則詳情、登記及個人用詞。
