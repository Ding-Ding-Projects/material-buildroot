# SDK 及工具鏈匯出

[English](sdk-export.md) · [輸出索引](README.md)

輸出檢視器有 SDK 匯出流程。先用具名目標佇列產生 Buildroot `sdk`，再瀏覽已接入輸出目錄，選擇產生嘅 `.tar.gz`。檢視提供兩分鐘預覽、壓縮檔摘要、輸入鎖、可用成功工作綁定、觀察到嘅編譯器名稱及 Linux 環境指引。匯出喺輸出根目錄建立唯一 `sdk-export-<id>`，內有 `sdk.tar.gz`、`README.md` 及 `sdk-export.json`，唔取代現有檔案。

壓縮檔按原位元組複製。主機收據記錄原相對來源、SHA-256、大小、來源及設定鎖、相符成功工作收據、壓縮檔資料，以及明確未核實工具鏈及使用方狀態。觀察目前輸入唔等於歷史建置來源證明。成功來源記錄喺排隊 `sdk` 真正成功後擷取頂層 `images/*_sdk-buildroot.tar.gz`，使用同映像建置相同嘅輸入、根目錄及執行環境綁定。舊工作或者缺少工作證據時可能冇匹配收據，只會標示未綁定，唔由檔名或者旁邊嘅成功工作猜測。

## 環境交接

使用相容 Linux，包括 WSL 2 或 Linux container，並以非 root 身份執行；呢個唔係 Windows 原生工具鏈。傳送完整匯出資料夾，前後比較壓縮檔摘要。檢查壓縮檔同腳本，解壓到全新空目錄，再按該 Buildroot 版本 SDK 指引檢視及執行 `relocate-sdk.sh`。

如果觀察到普通 `environment-setup` 檔案，先檢視內容再喺獨立 shell 載入。否則按該版本文件使用 SDK 明確編譯器路徑或者 `bin` 目錄。程式唔會建立替代環境腳本、由檔名推斷 ABI、執行搬移、載入 shell 檔案、啟動編譯器或者執行顯示層指令。觀察到嘅編譯器名稱只係資料，工具鏈同環境內容冇聲稱獨立鎖定。

## 界線及不支援情況

主機輸出身份會到期並重新綁定輸出根目錄。符號連結、檔案改變及根目錄被取代會被拒絕。gzip/tar 串流資料檢視上限為壓縮 4 GiB、展開 16 GiB、100,000 項、每路徑 4,096 位元組及兩分鐘期限。支援傳統/GNU tar 普通檔案、目錄、GNU 長名稱，以及正規化後仍喺單一壓縮根內嘅相對連結。不支援 PAX、絕對或逃逸連結、重複路徑、特殊檔案及多根壓縮檔。必須有搬移腳本同交叉編譯器檔名；唔會解壓或執行成員。資料通過准入唔等於可執行內容可信。

匯出持有原有來源及輸出路徑租約。預覽只可用一次，來源清單必須仍相符。目的地以獨佔方式新建，複製摘要相符後先寫最終收據。失敗保留未完成目錄並回報 `SDK_EXPORT_INCOMPLETE_RETAINED`，唔遞迴刪除回復。過期要重新檢視。目前原生輸出授權不能讀取嘅 Linux 專用輸出不能由此流程匯出。

## 驗收狀態

目前只係實作，測試、靜態分析、審查、實際操作及畫面擷取延後。未產生真實 SDK、執行搬移或環境腳本、編譯使用方、檢查 ABI 或在目標執行。收據記錄 `consumerBuildVerified: false` 同 `runtimeVerified: false`，桌面封裝唔改呢啲結論。
