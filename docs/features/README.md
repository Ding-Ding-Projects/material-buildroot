# Workspace features

- [Scheduled language and appearance preferences](scheduled-preferences.md): local
  rules, effective values, protected source enrollment and explicit draft recovery.

These workflows use the existing typed desktop bridge. No new HTTP API is added;
a category Postman collection is not applicable.

- [Managed container runtime](runtime-containers.md): local discovery, retained download caches, non-root execution and permission/lifecycle recovery.
- [Search and command consumers](navigation/search-commands.md): connected searches, picker workbenches and extensible context actions.
- [Destructive confirmation](destructive-confirmation.md): exact-destination, single-use consent for explicit clean builds.

- [Local history and exports](workspace-history.md): immutable revisions, restore consumers and bounded pages.
- [Appearance editor](appearance-editor.md): typed properties, motion, local history and scheduling.
- [Workspace tabs](workspace-tabs.md): retained project panels and explicit destination selection.
- [Background updates](../desktop/updates.md): verified downloads, explicit installation consent and recovery state.
