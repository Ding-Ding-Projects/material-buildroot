# 建立及繼續製作映像

[English](guided-image-creation.md)

映像係你想製作嘅 Linux 系統；專案就將來源、設定同輸出資料夾放喺同一個工作流程。先揀想做乜，指南之後會帶你建立或者開啟所需專案。

本文描述重整中嘅指南工作區。實際安裝啟動、由目前介面製作 ISO 同開機驗證仍然需要獨立完成。請睇每項操作嘅實際狀態，唔好將「已儲存選擇」當成「已核對成功」。

## 1. 選擇用途同目標

喺「映像」選擇「建立映像」。第一步唔會開啟原生資料夾選擇器，亦唔會開始建置。

| 欄位 | 點樣揀 | 幾時需要改 |
| --- | --- | --- |
| 映像名稱 | 保留建議名稱，或者輸入簡短、安全嘅檔名式名稱。 | 用容易認得嘅名稱標示草稿同建議匯出副本；佢唔會改 Buildroot 嘅實際輸出檔名。 |
| 模式 | 初次使用揀「簡易」。 | 「進階」會一齊展示同一份選擇，唔會重設草稿或者自行套用組合。 |
| 用途 | 已經有設定時，可以保留現有內容。 | 精簡、桌面、伺服器同專用設備只係製作意向；選好來源後先核對支援情況。 |
| 目標 | 指南嘅 ISO 目標係用 BIOS 啟動嘅 x86-64。 | 呢個建置流程唔支援只用 UEFI 嘅機器；未提供嘅目標唔可以當成已支援。 |

名稱有效後，選擇「下一步：來源同執行環境」。選擇會儲存喺本機；返回映像或者關閉程式，唔會令草稿變成執行許可。

## 2. 選擇專案同建置環境

按你嘅檔案情況，使用現有嘅建立、開啟、接入、匯入或者來源複製流程。取消資料夾選擇器後，映像草稿仍然可以繼續。建議專案名稱唔會取代你已經輸入嘅名稱。

映像頁亦會讀取真正已儲存嘅專案目錄。重新開啟程式後，專案可能需要重新授予資料夾存取權。請用正常選擇器選返原本想用嘅資料夾；儲存咗名稱或者路徑，唔代表已經有權限。揀咗另一個專案時，程式唔可以靜靜地將佢當成原本嗰個。

專案接納後，同一份映像選擇會延續到專案指南。改設定之前，先核對來源同執行環境。已儲存嘅 WSL 發行版或者 Docker 映像名稱只係選擇記錄，唔係存取成功證明。來源權限核對會列出準備允許執行嘅範圍；批准、設定同建置係分開嘅操作。

## 3. 選擇內容

讀取所選來源嘅實際支援能力後，先考慮套用預設組合。未提供或者自訂嘅選擇會保留並清楚顯示，唔會自行換成另一個選項。組合會向現有設定加入要求嘅套件；「精簡」唔代表刪除所有其他套件。

較複雜欄位旁邊有簡短說明、例子同完整文章。示範只會改變例子本身，唔會執行已安裝程式，亦唔係真實映像可用嘅證明。

## 4. 核對同套用設定

核對要求嘅變更、來源同建置環境。確認係你想要嘅變更，先明確勾選批准，再套用設定。來源、設定或者執行環境改動後，要重新核對。轉頁或者重開草稿，唔會還原批准或者成功結果。

如果專案已經有另一份映像草稿，可以選擇繼續原有草稿，或者明確取代草稿選擇。取代前會保留可復原副本，已記錄嘅工作識別亦會保留。儲存空間不足、無法儲存或者另一個視窗同時改咗資料時，程式會保留原有記錄，並指出邊部分未儲存。

## 5. 建置同檢查結果

設定確認後先開始建置。結果頁會顯示已記錄工作、重新整理記錄，並喺主機允許時提供取消操作。要求取消唔等於程序已經停止。

固定輸出係 `images/rootfs.iso9660`。映像名稱只提供另外匯出副本嘅建議檔名。檢查會核對目前檔案嘅位元組同結構，檔案可能來自較早嘅建置。工作成功或者結構檢查通過，都唔代表已驗證可以開機。

搵唔到已儲存工作時，先重新讀取呢個專案嘅工作清單。只有成功查詢並證明參照唔喺清單入面，先可以明確解除本機參照。解除只會改本機記錄：唔會停止程序、刪除輸出或者改主機工作記錄。重試前，請到建置頁核對運行中或者隔離中嘅工作。
