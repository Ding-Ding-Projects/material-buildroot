# 清理操作嘅確切目的地確認

[English](destructive-confirmation.md) · [功能索引](README.md)

建置工作區提供固定 Buildroot `clean` 目標。揀選唔會執行；提交先要求主機建立短時有效挑戰，綁定已接入嘅確切輸出目錄及完整建置請求，包括執行環境同資源選擇。目的地由主機解析，顯示層路徑唔授予權限。

程式對話框列明動作同輸出目錄。兩個獨立核取鍵及清理後需要重建嘅確認會啟用 0–100 滑桿，完成整條滑桿先可以提交。進度條跟隨滑桿，完成狀態獨立標示，尊重減少動態效果設定。支援英文、粵語及雙語。緊急離開同 Escape 會取消而唔提交，關閉後焦點返回原控制。確認兩分鐘後失效。

授權只用一次，綁定完整動作、工作區身份及確切輸出目的地，任何欄位改變都要新確認。主機先消耗授權，再將清理工作排隊；原有專案信任、路徑身份、資源准入及修訂檢查仍然必要。

`clean` 按 Buildroot 實作移除產生輸出，唔會自動開始下一次建置。先檢視清理實際結果，再明確選擇普通建置。清理工作唔可用一般重試，要重新提出及授權。

## 驗收狀態

本輪快速交付只完成來源實作，未執行測試、靜態分析、實際操作、畫面擷取或者破壞性工作。未觸碰、單鍵、雙鍵、部分及完整滑桿、取消、焦點、鍵盤、輔助科技、減少動態效果、本地化、到期、單次防重放及真實成功失敗路徑全部待驗收。唔宣稱已覆蓋完整目標目錄或者程式其他破壞性操作。
