# 可重現記錄及授權合規證據

[English](reproducibility.md) · [功能索引](README.md)

主機結果 API 只讀取已接入專案輸出目錄，唔執行輸出、解壓、寫入輸出目錄或者接受呼叫方提供根目錄。

## 記錄所選輸出

`artifacts.manifest` 接受 `workspaceId` 同 `paths`，回傳排序相對路徑、位元組大小、SHA-256、完整性摘要及來源與設定內容鎖。雜湊前後擷取輸入，快照改變會拒絕。外部樹沿用建置意圖政策，原有界限及符號連結限制仍適用。

`all` 工作成功後，排程器仍持有來源及輸出租約時，主機收集專用建置後收據，綁定排隊輸入意圖、執行環境選擇摘要、來源/輸出/外部根身份及工作 ID。前後輸入要相同，根身份要與執行前相符，含符號連結來源快照唔可作建置證明。映像探索上限 10,000 項及 4 GiB，收集期限 60 秒，每次讀取之間檢查期限，單檔雜湊會完成先檢查；來源擷取有自己更嚴格限制。收據最多 4 MiB，以原子方式儲存在主機本機資料，唔寫入所選輸出。

只有所選路徑、摘要、大小及來源/設定鎖符合主機收據，而且工作真正達到 `succeeded`，清單先標示 `buildTimeBinding: true`。主機重新驗證收據摘要、結果、排隊意圖、執行環境摘要及根身份。證據缺少或改動唔會建立綁定。收集失敗明確標示 `unbound`，唔虛構來源證明，亦唔改寫建置本身成功。增量建置可以重用輸出，收據只記錄成功執行後觀察到嘅內容，唔證明每檔重建。

其他記錄仍為 `current-input-observation`，`buildTimeBinding: false`，包括舊輸出、非映像目標、設定不可用、輸入改變、輸出不符或者缺少證據。工具鏈、環境內容及上游修訂鎖唔會猜測。下層 API 仍可接受持有證據呼叫方嘅明確已驗證鎖。

## 比較重複建置

經已有授權匯出流程保留兩份記錄，再放入已接入輸出目錄。`artifacts.compare` 接受 `workspaceId`、`beforePath` 同 `afterPath`；每份最多 4 MiB、10,000 個唯一正規相對路徑，先驗證大小、摘要、輸入鎖及記錄摘要。

結果分清新增、移除、位元組改變、輸入鎖改變、缺少來源或設定鎖、冇建置關聯、同一工作觀察及執行環境選擇改變。綁定要由實際本機工作及主機收據重新核實，自填來源欄位或自行計算 JSON 摘要唔能代替。冇指定收據時，最多搜尋最近 100 個匹配工作。

相符結論要求兩個不同成功工作，只涵蓋所選位元組及記錄輸入/執行環境選擇，唔認證工具鏈、環境、未選檔案、執行正確性、全新重建或者差異原因。時間戳及隨機性只係調查線索。舊完整性編碼不相容要重新產生。收據只綁定原接入根及本機工作儲存，搬走輸出或者喺其他安裝匯入唔會轉移信任。

## 收集授權及 SBOM

`artifacts.compliance` 讀取既有 `legal-info`，回傳檔案摘要、有界預覽、完整 CSV 套件記錄、原始授權聲明、清單路徑及摘要、解析缺口同 SPDX 2.3 證據文件。CSV 處理引號、逗號同換行，要求套件、版本及授權欄；不支援格式明確列為缺口。

每份完整 CSV 最多 2 MiB，總 CSV 16 MiB，既有收集最多 10,000 項。壓縮檔只讀資料，唔解壓。授權字串保留來源聲明，SPDX 斷言仍為 `NOASSERTION`，唔判定法律相容性或者認證合規。收集時間只係觀察資料，唔屬輸出可重現聲明。

## 交付狀態

此變更接通現有結果服務及主機請求登記，冇新增顯示層控制。快速實作模式下，真實結果操作、匯出畫面、重複建置、產生 legal-info 及對抗驗證仍未核實。
