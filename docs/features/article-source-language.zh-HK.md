# 文章來源語言資料

[English](article-source-language.md) · [文章目錄](README.md)

文件製作器根據已追蹤來源路徑判斷文章語言。精確 `.zh-HK.md` 結尾表示粵語（`zh-HK`）；其他已接納Markdown沿用英文（`en`）預設。呢個跟隨既有翻譯檔名規約，唔分析正文、唔自動翻譯，亦唔證明文章已完整翻譯。

文章資料顯示 **Project record · Cantonese source** 或 **Project record · English source**，同相應粵語介面標籤。每個標籤各自宣告語言。渲染後Markdown正文有明確 `lang` 屬性，獨立於訪客選擇英文、粵語或雙語頁首。切換偏好只改介面標籤，唔改正文或來源身分。外圍介面保留英文，翻譯文字片段各自標記語言。

文章路由、原始來源連結、書籤同Markdown渲染不變。正式檢查器逐篇驗證預期標籤同正文語言。`node website/test-article-language.mjs` 測兩種來源，拒絕標籤互換、欠標籤、欠語言同正文語言錯配，亦核對內容精確保留。真正瀏覽器檢查同以上來源檢查分開。

原文嘅粵語短說明概括同一界線：檔名規約唔等於翻譯證明，正文同介面語言分開，網址同來源不變，實際顯示同鍵盤操作仍需獨立驗證。
