# 專案工作區分頁

[English](workspace-tabs.md) · [功能索引](README.md)

桌面為每個已接入專案保留一個操作面板，身份使用可信登記服務回傳嘅穩定工作區 ID。再揀同一專案會聚焦原面板；不同專案各自保留設定修改、來源狀態、輸出及工具表格。關閉導覽唔會銷毀面板或者刪除專案，原生標題列控制不變。

## 開啟目的地

「新增分頁」目錄包含根頁面、全部操作工作區、設定分類、工具章節及設定精靈。工具分頁保留開啟時專案，返回時先選中該專案再進入目的地。普通導覽只改目前介面，唔會自動增加工具分頁。目錄預設文字搜尋，旁邊獨立正則工作台使用工作執行緒期限及表達式驗證。

分頁列預設左邊，可經管理面板或者右鍵停靠四邊。本機保存開啟身份、釘選、次序、群組名稱、群組次序、成員、摺疊及停靠，呢啲資料唔授予執行權限。重新啟動後仍要原生選擇專案資料夾續期權限，重新接入沿用穩定分頁身份。

釘選區獨立捲動。拖放可以排序及移動群組，Alt 加相應方向箭嘴排序，Alt+P 釘選。箭嘴移焦點，Home/End 到邊界，Enter/Space 啟用，管理介面亦有具名按鈕。四邊標籤都保持橫向，窄側列保留有完整無障礙名稱嘅圖示按鈕。

## 搜尋及管理

即使溢出仍可使用分頁管理器，全部分頁、群組及各群組成員各有獨立搜尋與正則狀態。按匹配或不匹配關閉需要有效非空查詢，先預覽所選標籤，除非明確包含，否則唔處理釘選。未儲存語言及排程決定沿用原有處理，保留專案面板隱藏或關閉時仍保留草稿。

## 共用指令及主機視窗探索

桌面透過 `registerCommandActionProvider` 登記真實目的地回呼，指令面板同新增分頁目錄共用清單。啟用時重新解析目前可呼叫項目，關閉目錄，再呼叫原有處理端。被限制或者移除項目唔會由舊標籤復活。

總搜尋由主程序取得視窗清單。只有已登記程式視窗及已獲准主框架文件可發佈有界分頁資料。主機指派視窗身份，文件導覽或崩潰時清除記錄，視窗銷毀後移除。資料只存記憶體，唔授予專案、路徑或任意指令能力。啟用只可到現存已登記視窗嘅分頁，要求正常導覽並保留草稿決定。

目前桌面主機只建立一個視窗，冇新增視窗操作，故清單只報一個實際視窗。登記架構可以支援明確登記嘅其他視窗，唔表示此版本會建立。缺少主機橋接顯示不可用，唔虛構顯示層視窗記錄。分頁列、總搜尋、群組搜尋及每組成員搜尋使用分開表達式工作台，切換模式唔借用其他查詢隱藏狀態。

分頁及群組右鍵動作開啟非模態外觀編輯器，亦有 Shift+右鍵路徑。字型、顏色、幾何、狀態、匯出、重設及預設由外觀編輯器處理。穩定身份同次序、目前目的地分開。

## 驗收及限制

快速交付模式刻意未執行操作、無障礙、比例幾何、重啟持續儲存及畫面擷取。源文章記錄 `e1615cde49e4dbc80a86b3248de8431c30a4b77f` 曾完成正式建置，但後來工具擁有權同目錄修改已超越該版本，唔可以當最新證據。建置成功只證明編譯。穩定身份嘅分頁/群組外觀整合有自己獨立驗收，唔由此宣稱通過。目錄係可到達目的地，唔係任意指令；持續儲存資料唔授權執行。

多視窗啟用、外觀持續儲存、授權撤銷及版面幾何全部仍待實際驗收。
