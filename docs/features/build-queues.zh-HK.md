# 並行專案建置佇列

[English](build-queues.md) · [功能索引](README.md)

建置工作區提供由主機授權嘅專案佇列及唯讀工作終端。檢視佇列狀態可查看全域 CPU、記憶體、儲存空間及並行預留，再編輯同儲存全域准入預算。預算保存在本機使用者資料中，限制工作獲准開始，唔直接限制作業系統執行；降低預算唔會終止現有工作，新工作等到現有預留符合新預算先開始。

每個專案保留先入先出順序。解析後嘅來源、輸出同外部樹路徑共用修改租約，重疊專案唔能夠同時寫同一輸出樹。獨立專案喺全域預算及最新執行環境資源觀察允許時可以並行。來源或者設定改變會阻止原有請求，唔會偷偷更新已排隊意圖。

更新專案佇列，開啟某個工作終端，再讀取下一頁，可查看該工作已記錄輸出。主機每次範圍操作都核對專案身份及工作擁有權。終端唔接受任意指令，每次讀 50 筆，畫面保留最多 500 筆。切換專案會清除畫面上嘅終端內容，唔會刪除已儲存工作。

取消目前工作需要最新序號及擁有權。序號過期要先更新。現有預留會保留到執行環境取消及清理流程實際完成；清理未核實就維持隔離，要求主機明確核對，唔會強制停止無關執行環境。

已儲存預算格式錯誤會停止准入，無效更新唔改原有預算。資源探索失敗同樣阻止新工作獲准執行。

## 驗收狀態

此實作由只建置交付模式準備，刻意未執行測試、靜態分析、實際操作或畫面擷取。建置結果只證明編譯或封裝，唔證明並行、取消或者介面行為已驗收。
