- [Opt-in HTTPS companion](companion.md)

The parser accepts data only. The broker adds a trusted-host settings transaction and strict reply/event translation. Local preferences use an owned-frame IPC bridge. Those IPC-only boundaries do not require a Postman collection.

The opt-in companion separately exposes authenticated HTTPS endpoints for pairing, session discovery, scoped actions and disconnection. Its complete protocol and privacy limits are documented in the companion article. Its category-level [Postman collection](postman/companion.postman_collection.json) and the product [master collection](../postman/material-buildroot.postman_collection.json) cover all four routes and all six typed actions. Both are generated by `node scripts/api/generate-postman.cjs` and replayed in order against a real loopback HTTPS companion by `tests/postman-collections.test.cjs`. They contain placeholders only. Do not enter production pairing credentials or session values into shared collections; keep the challenge and CSRF token in unshared current values.
