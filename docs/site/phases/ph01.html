Detailed contracts, evidence admission and dependencies

Check a task only after its required evidence passes. Completion is recorded in the source roadmap. This page covers one phase.

All 19 focused ledger cases and independent clause/surface review passed. This proves the narrow planning artifact only; complete semantic admission and all consumer implementation remain open. The private documentation format is inactive for this public product. Planning record.
    • PH01-T01-C02-A Reconcile and verify only the five Group A identities, preserving all prior IDs and adding 15 independently supported detail clauses: 109 identities, 436 records and 427 requirements. Independent review/refutation, parent preserved-ID readback and all 20 focused ledger/omission cases passed. No product delivery or overall semantic acceptance is claimed. Bounded evidence.

The reconciliation index maps all 109 identities and 427 current requirements, with bounded independent review. Exhaustive clause/research interpretation and actual consumer admission remain open.

    • PH01-T02-C02 Admit concrete implementation consumers, localized articles/copy, persistence, detailed runtime/capture tuples and tests before each feature is implemented. All 436 records now have explicit planned identities and tuple axes, but reserved paths are not admitted consumers or runtime evidence.
    • PH01-T02-C03 Implement and locally verify the representative serialized-request parser, strict schema and typed request union. Nine focused tests and independent review pass; this child grants no authority and does not complete production IPC or any effectful action. Evidence.
  • PH01-T03 [R (A/D/C admission only)] Admit genuine registered Material Design 3 components and every native/browser/tool adapter: pin provenance, compatibility, licenses, redistributability, offline payloads and full installer size.
  • PH01-T04 [R (A/D/C admission only)] Create deterministic screen/state references, a direct reference renderer and hand-written parity/control maps; include reduced-motion, accessible structured canvas alternatives and negative textbox-substitution checks. Thirty reference states and local build tooling are authored. Two source-bound builds and focused runtime repairs are verified; full reference interaction, accessibility, typography and tuple acceptance remain pending.

Future C, remaining D and PH10-dependent records stay unchecked and do not create a backward prerequisite. Blocked proof within the declared scope prevents this phase from being called complete.
