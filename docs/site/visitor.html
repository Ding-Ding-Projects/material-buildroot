AUTHENTICATED COMPANION已驗證瀏覽器連線

Connect to your desktop連接桌面程式

Use the desktop app to create a short-lived challenge for this exact website origin and read-only scopes. Paste that challenge here and approve the request on the desktop. The page sends requests only to the entered private IP; it uses no project proxy, tunnel or TLS bypass. Your browser network settings still apply. Use a certificate your browser already trusts.請喺桌面程式建立只適用於呢個網站來源同唯讀權限嘅短期挑戰碼。將挑戰碼貼喺呢度，再喺桌面批准。此頁只會向輸入嘅私人 IP 發送要求；不會使用項目代理、通道或繞過 TLS 檢查。瀏覽器網絡設定仍然適用。請使用瀏覽器已信任嘅憑證。

This page only requests workspace.read, projects.list and jobs.list. It does not submit builds, change projects, cancel jobs or access shell commands.呢個頁面只會讀取 workspace.read、projects.list 同 jobs.list。唔會提交建置、修改項目、取消工作或執行 Shell 指令。

Desktop connection桌面連線

Read workspace讀取工作區List projects查看項目List jobs查看工作

Job states show the latest host response only. Closing this page or disconnecting does not cancel host work.工作狀態只反映最近一次主機回覆。關閉頁面或中斷連線都唔會取消主機工作。

The host session can remain active for up to one hour, including after this page closes. Use Disconnect before leaving.主機連線最多可保持一小時，即使關閉此頁亦一樣。離開前請按「中斷連線」。

Browser TLS checks remain enabled. Certificate, CORS, browser private-network access and local network policy can block a connection; this page cannot bypass them. The challenge must be approved on the desktop.瀏覽器 TLS 檢查會保持啟用。憑證、CORS、瀏覽器私人網絡存取或本機網絡政策均可能阻止連線；此頁無法繞過。配對必須喺桌面批准。
