Read-only browser companion唯讀瀏覽器 Companion

The visitor workspace can request an owner-approved, exact-origin read-only session for workspace summaries, project names and job states. Pairing requires a current desktop challenge, a browser-trusted HTTPS certificate and working CORS/private-network access. The page does not start builds or control the desktop.訪客工作區可要求由使用者批准、限定網站來源嘅唯讀連線，用於查看工作區摘要、項目名稱同工作狀態。配對需要有效桌面挑戰碼、瀏覽器信任嘅 HTTPS 憑證，以及正常 CORS／私人網絡存取。此頁不會啟動建置或控制桌面。
