固定桌面執行環境更新至 44.9.0

English · 桌面文件索引

桌面執行環境套件同專案本機可攜式封存檔由先前固定嘅 Electron 44.7.2 更新至 Electron 44.9.0。應用程式版本維持不變。現有建置入口保留完整封存檔校驗碼、解壓檔案清單、可攜式啟用程序，以及綁定來源版本嘅輸出檢查。按版本分開嘅快取會保留較早執行環境世代；今次改動唔會修改已安裝應用程式嘅設定、電腦安全設定、執行旗標或主機設定。

官方正式版本 v44.9.0 喺 2026-10-17 發佈。Windows x64 ZIP 為 158,625,558 位元組，SHA-256 係 88e08039d0ef359bab9f674e8051fa103bd8628ea7c5a5e1daaa610a8a0c6931。發佈資產摘要同已下載嘅官方 SHASUMS256.txt 一致。校驗碼檔案本身嘅 SHA-256 係 f9485deeff752391c11c443e62f92eb03a25be39d899405264635c241d121767。npm 套件鎖定檔使用已發佈嘅 44.9.0 tarball 完整性值，冇一併升級其他套件。

呢個係受支援嘅執行環境更新候選版本，唔代表已證實修復觀察到嘅原生 renderer 結束問題。較早觀察包括結束碼 0x80000003 同 0xC0000005，兩者都唔足以確定應用程式來源碼成因。建置成功只驗證封裝同來源綁定；啟動、持續原生運作、renderer 結束行為同受影響流程，仍須喺實際建置嘅應用程式另外驗收。今次改動唔會發佈產品版本，亦唔會自動更新已安裝應用程式。

來源：官方發佈、官方校驗碼、npm 套件中繼資料。
