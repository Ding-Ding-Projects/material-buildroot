ISO 設定組合與韌體

English · 欄位目錄 · ISO 工作流程

用途與建議預設

呢個引導設定用嚟製作 x86-64 BIOS 光碟映像，採用 GRUB2 同初始 RAM 檔案系統。可以將韌體理解為電腦開機時讀取嘅第一份指引，開機載入器再負責載入 Linux。來源必須已啟用 x86-64 同 Linux。Easy 模式會讀取真正嘅來源，只有所需選項可以選用時先提供此設定，唔會憑空假設某個 Buildroot 版本或其他韌體已獲支援。

例子與限制

設定識別碼係 x86_64-bios-grub2-initrd。韌體用 BIOS，開機載入器用 GRUB2，檔案系統用 initrd，輸出格式用 ISO9660。此設定冇配置或驗證 UEFI 同混合 USB 啟動。核心同原有套件選擇仍由項目決定；選咗 ISO 唔代表會自動加上桌面環境。

RAM 選項代表甚麼

ISO 係一個光碟映像檔案。引導嘅 initrd 選項會喺電腦啟動時，將 Linux 根檔案副本載入記憶體。程式運行期間可以改動 RAM 副本，但唔會因此改寫 ISO 檔案，亦唔證明重新啟動後會保留改動。持久儲存須另外設定同驗證。

已擷取嘅 Buildroot 2025.02 BR2_TARGET_ROOTFS_ISO9660 說明，區分直接唯讀 ISO 根目錄同可讀寫嘅 RAM 根目錄。該來源嘅 BR2_TARGET_ROOTFS_ISO9660_INITRD 預設為 y，會將根檔案系統連同核心同載入器分開封裝。來源係 fs/iso9660/Config.in 第 1 同 68 行，SHA-256 為 172e3e70c48df32d47e29d76b65ce60b48906ee1231a9426aaad6130309a7cc2，記錄喺來源涵蓋清單。以上說明綁定此版本，唔係通用相容性證據；目前指南仍會喺套用固定組合前檢查所選來源。

組合控制項嘅可選指南

「已偵測映像組合」正上方嘅小型資訊按鈕，會開啟非模態說明同練習例子。揀「RAM 副本例子」或「唯讀光碟例子」，再按「試用例子」，查看改動範例筆記會代表甚麼。光碟選項只比較來源替代方案，唔會更改真正嘅簡易 ISO 組合。產生檔名例子仍然係 images/rootfs.iso9660。

「重設例子」會還原 RAM 例子。「關閉組合指南」或 Escape 會將焦點交回資訊按鈕，並丟棄例子狀態；再次開啟會重新開始。每份指南各自保存練習狀態，唔會持久儲存、複製即時記錄或發送主機操作。例子唔會建立檔案、權限、設定或建置；真正操作仍用原有流程控制項。

此項指南嘅控制清單：iso-profile-info 對應 iso-profile-control 同 iso-profile-guide。按鈕有本地化輔助名稱、滑鼠停留／鍵盤焦點提示、最少 44 像素目標同展開狀態。窄畫面時面板仍喺內容流程之內。繪製器測試涵蓋鍵盤開啟、焦點返回、獨立例子、重設、本地化同冇主機呼叫；原生驗收另外進行。

復原與進階控制

任何必要選項無法使用時，Apply 會保持停用。空白或處理器唔合適嘅設定，可用來源實際提供嘅電腦起點，核對取代同意並重新批准已更改設定嘅權限，再檢查一次。Advanced 模式保留套件預設同完整配置編輯器，處理其餘未支援情況。手動啟用 UEFI 唔能夠證明此 BIOS 流程支援 UEFI。
