ISO 輸出與驗證

English · 欄位目錄

用途與建議預設

Buildroot 會喺已採用嘅輸出根目錄之下產生 images/rootfs.iso9660。檔名同位置由主機設定組合決定，唔需要自行研究副檔名。如果要保留之前嘅產物，採用項目時應選另一個獨立輸出目錄。

例子與覆寫限制

相對路徑 images/rootfs.iso9660 係有效例子。引導檢查器唔接受絕對路徑或任意檔名。正常增量建置可能更新自己產生嘅檔案，但此流程唔會刪除無關檔案。

既有 ISO 匯出功能可以將 ISO 複製成新名稱，目標已存在時會拒絕操作。呢個功能係複製 ISO，唔係將原始磁碟改個名就變成可啟動光碟。

驗證與復原

Inspect 會報告位元組數、SHA-256、描述符範圍同 BIOS El Torito 開機目錄結構。已存在嘅檔案可能係舊工作留下，分享之前要將雜湊值同預期建置證據連繫起來。中繼資料有效、建置成功，同實際啟動成功，係三個分開嘅結果。

找唔到輸出時，應查看工作同配置。描述符範圍或開機目錄檢查無效時，要修正原因再建置，唔好將原始磁碟重新命名成 ISO。已記錄嘅特定映像啟動結果見啟動證據，唔代表所有將來輸出或硬件都通過。
