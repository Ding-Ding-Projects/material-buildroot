有型別設定控制

English · 桌面索引

設定工作區使用已接入解析器回傳嘅實際 Kconfig 符號型別。布林開關、可指派三態選擇、十進位整數、十六進位數值及字串會將完成嘅編輯送入依序協調佇列。數值同字串喺值變更完成時提交，唔係每打一個字就提交。

佇列每次操作都使用上一個回覆嘅最新修訂。復原同樣排喺先前編輯之後。請求被拒絕或者結果不確定時，自動處理停止，待處理編輯會保留；使用者可以檢視並明確重試或者捨棄。來源執行信任仍屬必要，設定變更令原授權範圍失效時可能要重新取得。

主機以原子方式取代 .config，並記住原本有冇檔案。協調失敗會還原原先內容或者原先不存在嘅狀態。復原歷史只限目前主機工作階段最近二十次套用，綁定來源、輸出、設定範疇同預期修訂，拒絕外部改動。成功復原會更新下一筆歷史嘅預期修訂；重新啟動後唔保留呢份復原歷史。

要求值同有效值差異包括協調新增、改動及移除嘅符號。面板喺控制旁保留最新差異。解析器說明、依賴表達式、數值範圍同選單路徑來自來源本身。
