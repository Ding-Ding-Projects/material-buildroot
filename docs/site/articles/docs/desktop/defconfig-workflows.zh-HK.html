defconfig 工作流程

English · 桌面索引

設定工作區有 Buildroot defconfig 瀏覽器。先授予設定執行信任，再更新目錄。程式先列出來源 configs/，再按儲存次序列出每棵目前已授權外部樹。同名項目仍然獨立，保留來源身份及內容摘要。每次顯示最多 250 個篩選結果。

套用前要明確確認取代。主機重新整理目錄，核對修訂及所選內容，再將主機讀取嘅位元組送往設定服務，沿用修訂、信任、協調及回復規則。唔執行顯示層傳來嘅 shell 指令或者檔案路徑。

最小設定儲存使用固定 BR2_DEFCONFIG 覆寫，將 Buildroot savedefconfig 輸出寫到專案獨立輸出目錄內嘅 material-minimal-defconfig。目的地已存在就停止；再次儲存前，使用者要明確搬走該檔案。獨立 JSON 收據記錄 SHA-256、來源及設定修訂、執行環境同外部樹順序，避免覆寫由 BR2_DEFCONFIG 選中嘅原始來源設定。

來源位元組、設定、執行環境、外部樹順序或者授權改變，就需要重新信任或者更新目錄。缺少原生授權、不安全連結、過大檔案及專案並行操作會停止流程。外部樹授權只限本次工作階段，重新啟動後要續期。

驗收狀態

此流程嘅來源實作已備妥，唔代表完整產品驗收。本輪未操作實際執行環境、檢查畫面或執行自動檢查，相關結果仍未核實。
