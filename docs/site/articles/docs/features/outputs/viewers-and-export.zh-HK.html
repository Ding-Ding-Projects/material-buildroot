輸出檢視及已驗證匯出

English · 輸出索引

瀏覽流程

開啟已接入專案「Artifacts」，選輸出根，再瀏覽目錄。主機發不透明項目身份，顯示層唔可傳絕對路徑。身份十五分鐘失效，根更新亦失效，建置改變位元組後要重新更新。

選檔查看格式、長度、文字、支援壓縮成員、分割區、簡單依賴圖或 CSV。普通預覽最多讀 1 MiB。文字、XML、HTML、SVG、CSV cell 及圖標籤只當文字，唔執行 markup、公式、指令、連結或腳本。

SHA-256 係明確操作，可提供預期摘要。相同只係位元組比較，唔係來源認證或授權判斷。普通檔案最多 16 GiB、串流兩分鐘，讀取前後核身份及修改資料。

支援格式及限制

格式 界線
目錄 每次最多檢查 1,000 項，冇符號連結/特殊檔，解析後包含檢查及身份再驗
TAR 固定 header 摘要，最多 1,000 成員；link/extension 只顯示，PAX/GNU 唔當解壓指令
ZIP central directory 最多 1,000 項及 1 MiB metadata，不支援 multi-volume/ZIP64，唔 inflate
ISO9660 primary-volume 根目錄最多 1 MiB、1,000 項，唔深入子目錄或解析 Joliet/Rock Ridge
磁碟映像 有界 MBR/GPT 唯讀可選分割圖及同等表格，唔修改、掛載或修復，sector 固定 512 位元組
ext-family 只基本 superblock，唔瀏覽檔案或判定一致性
Graph 簡單 directed DOT edge 子集，最多 200 edge、60 可見節點，揀節點篩選表格，唔係完整 Graphviz
CSV/授權來源 最多 201 筆、32 欄、每 cell 4,096 字元，唔作法律結論，截短預覽唔證明收集完整

此元件未實作壓縮 TAR、磁碟內通用檔案瀏覽、PDF 圖 rasterization、raster 圖 decode 或解壓。不支援資料明確不可用，唔當檢視成功。

匯出流程

輸出摘要同既有客體轉換提供 raw、VMDK、VDI、QCOW2、ISO、OVA。揀來源、輸入新 basename 及副檔名、預覽再確認。顯示層只送主機檔案身份，主機解析路徑。預覽綁 SHA-256，兩分鐘到期，唔覆寫。

磁碟解析/轉換要經主機 resolver 接入原生 qemu-img，PATH 名稱唔係可信權限。缺少就錯誤，唔偷偷下載或執行。輸入最多 16 GiB，虛擬容量 64 GiB；QCOW2 backing、snapshot、加密及未知 incompatible feature 先拒絕，差異 VDI 拒絕，VMDK 只接受目前主機轉換服務產生且未改磁碟，唔讀任意外部 extent。

預覽同執行都先複製到私人目錄，核摘要先原生解析，再檢查 snapshot 外部參照。QEMU 收明確輸入格式及固定主機有界參數，唔收顯示層 CLI。輸出 metadata 要符合格式及容量，qemu-img compare 要邏輯內容相同先發佈；最終獨佔複製並讀回 SHA-256，原檔不變。

ISO 只係已識別 ISO9660 原位元組複製，唔由 rootfs 編寫可啟動 ISO。OVA 用 stream-optimized VMDK、固定 OVF、SHA-256 清單及 USTAR，宣告一 CPU、1024 MiB RAM、SATA、冇網絡。每 USTAR 項要符合八進制大小限制，唔保證匯入或開機相容。

清單、合規及重複建置

核取輸出再「建立及儲存清單」，主機擷取輸入鎖及所選位元組摘要，以不透明身份 adapter、修改租約及獨佔方式喺輸出根儲存主機命名 manifest-<uuid>.json。唔收顯示層目的地或替代。

面板顯示摘要、逐檔摘要及真來源狀態。「只觀察目前輸入」代表冇匹配成功工作收據；「綁定成功本機工作輸出收據」會顯示工作、收據摘要、時間及執行環境選擇摘要，兩者唔可以共用成功標籤。

將新記錄或瀏覽器既有清單分配前/後，交現有檔案比較服務。顯示精確狀態、兩邊綁定、工作是否不同、執行環境差異、缺鎖、改鎖及改輸出。同一成功工作重觀察唔係兩次建置。位元組/鎖相同唔證明全新重建、完整輸出、工具鏈/環境內容、匯入或開機。增量可重用檔，根更新或身份到期要重揀，唔默用過期身份。

「收集 legal-info」用既有合規服務，表格顯示套件、版本、來源授權及清單路徑、解析失敗與摘要。狀態及只來源聲明限制可見，顯示層唔推斷 SPDX expression 有效、法律相容或者義務。

驗收狀態

此模式排除測試、審查、靜態分析、實際操作、轉換及畫面。新正式收據必須綁確切來源。此實作唔證明轉換、解析、檔案檢視、鍵盤、本地化版面、匯入或開機，實際驗收保持未完成。
