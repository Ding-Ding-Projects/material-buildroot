遠端 Buildroot 執行環境

English · 功能索引

執行環境工作區提供目標登記、來源傳送、建置派送、保留工作觀察、取消請求及摘要核對輸出下載。P41 批准嘅四種形態如下。

目標 SSH 主機 執行
linux-process Linux 非 root Python 監督程序及 make
linux-docker Linux 非 root 監督程序、摘要鎖定 Linux container 及明確非 root UID/GID
windows-wsl Windows 固定 wsl.exe 進入所選發行版，再以非 root Python 及 make 執行
windows-docker Windows 主機 Python 監督程序、摘要鎖定 Linux container 及明確非 root UID/GID

登記及必要工具

經現有工具登記選擇可信 SSH 執行檔。認證使用作業系統 SSH agent，呢個流程唔接受密碼或者私鑰內容。目標要已有 Python 3 及所選執行環境，唔遠端安裝工具、提升權限、重啟或者改登入狀態。

用「從 JSON 登記目標」選本機文件。批准原生確認前要獨立查核主機公開金鑰。文件只含連線資料及公開主機金鑰，唔含憑證。

{
  "version": 1,
  "name": "Build server",
  "host": "builder.example.org",
  "port": 22,
  "username": "builder",
  "hostKey": "ssh-ed25519 REPLACE_WITH_VERIFIED_PUBLIC_KEY",
  "kind": "linux-process",
  "root": "/home/builder/material-buildroot",
  "distribution": null,
  "image": null,
  "uid": null,
  "gid": null
}

例子刻意冇可用金鑰，要換成獨立查核嘅真實公開值。根目錄要已存在、為解析後路徑、冇符號連結組件，而且所選帳戶可寫。Linux/WSL 用絕對 Linux 路徑，Windows Docker 用絕對 Windows 路徑。空格、shell 特殊字元、逗號及相對組件會被拒絕。每目標有專用受保護 known-hosts，必須嚴格檢查；換金鑰要另外檢視登記，唔自動接受。

windows-wsl 嘅 distribution 要係精確發行版名稱。Docker 目標嘅 image 要係本機 @sha256:... 參照，uid 同 gid 皆非零，並有 Linux engine 及包含 Buildroot 必要工具嘅映像；程式唔拉取映像。帳戶要有 Docker 存取，指定 UID/GID 要可寫輸出掛載。container 冇額外能力，使用 no-new-privileges，但保留 Buildroot 下載網絡。

登記只探測根身份及協定，唔宣稱完整工具或執行準備檢查通過。重啟清除連線權限，進一步工作前要「重新連線及驗證身份」。

來源傳送及工作

喺工作區選擇目前授權專案，用「傳送目前專案」。主機重新核對權限，取得來源及輸出修改租約，擷取來源/設定意圖，再建立全新獨佔來源壓縮檔。內容包含真實來源但略過 .git，以目前輸出 .config 代替來源根設定。接受前再擷取意圖，唔以顯示層路徑或者測試壓縮檔代替權限。

目前只支援本機可讀、普通檔案、冇外部樹專案。WSL Linux 儲存、外部樹、符號連結及特殊檔案會明確不支援，唔會默默漏資料。原有來源擷取最多 512 MiB 等限制仍適用，與四種遠端執行形態分開。

來源及個別輸出傳輸上限為 1,107,296,256 位元組，以固定 1 MiB 區塊、精確偏移、有界回覆及全串流 SHA-256 核對，唔整份載入記憶體。遠端解壓最多 100,000 項及相同展開上限，拒絕重複路徑、穿越、裝置名、連結及特殊檔案。上載首塊前建立獨佔 UUID 目錄及未完成收據。明確重試用新目的地及新來源綁定，唔自動續傳；中斷本機壓縮檔、遠端串流及下載都保留。

主機計算摘要，遠端監督程序獨立驗證，再記錄完整普通來源檔案清單摘要。建置請求綁定主機及儲存身份、傳送 ID、來源摘要、目標及並行數。支援 all、sdk、legal-info、source。執行前核對清單，再複製到獨立工作目錄；已檢視 .config 成為新輸出設定。Docker 將複製來源唯讀掛載，輸出可寫。

原生確認明確批准執行已傳送來源。可信 Makefile 本身可以執行指令，固定傳輸唔係敵意來源沙箱。主程序構造全部 SSH 指令，經標準輸入送綑綁監督程序。顯示層唔可提供 shell 片段、執行檔、憑證、任意遠端路徑或監督程式碼。

既有工作管理器只記錄本機派送，成功排隊代表傳輸完成，唔係遠端建置成功。觀察係獨立明確操作。遠端保留工作同心跳，過期 running 變 unknown，中斷派送唔自動重播。重啟保留工作 ID，但要重新連目標；遠端主機重啟只觀察復原，唔重開建置。

取消寫確切工作擁有嘅請求標記，監督程序停止其子程序群組，或者核對 Docker 工作標籤先停止該 container。確認收到取消唔證明終止，要再次觀察終止收據。本機程式關閉只取消自己 SSH 傳輸，唔宣稱獨立遠端工作已停。

輸出及保留

只有監督程序記錄建置結束碼零先列出輸出。清單只含該工作 output/images 直接普通非連結檔案、長度及 SHA-256。每檔下載同樣最多 1,107,296,256 位元組；選中時遠端計一次摘要，各區塊核對身份、大小及偏移。本機邊寫邊計摘要，完整長度及摘要相同先記 verified，更大映像留喺目標。

原生目錄選擇器提供本機目的地權限，每次新建獨佔目錄及未完成收據。遠端檔案仍要匹配原摘要，本機亦獨立核對。下載唔執行或掛載輸出，部分資料及收據保留，唔自動清理或覆寫。

資源預留及限制

遠端派送沿用工作管理器同全域排程器之外部預留 API。每次預留所選 CPU、4 GiB 記憶體及 16 GiB 儲存，資源由身份綁定監督程序觀察。CPU/記憶體按主機身份合計，儲存按主機及登記根合計。container 額外設 CPU/記憶體限制；普通程序預留只係准入會計，唔係作業系統配額。

斷線或重啟後，不確定工作仍保留預留，恢復預留先佔用預算，再接受本機工作，唔會續期來源權限。只有身份及來源綁定終止收據可釋放。取消回覆、傳輸成功或經過時間都唔得。工作唔自動重播，預算使用既有共用儲存及修訂。未知結果可能要操作者復原，冇遠端收據唔證明程序停止。

「讀下一頁記錄」最多取確切工作 64 KiB，核對檔案身份及遞增位元組偏移，每工作階段最多顯示 1 MiB，移除控制字元。記錄係不可信來源輸出，可能含敏感自產文字，保持原文，唔匯出或送遙測，完整記錄留喺目標。

驗收狀態

快速交付只完成來源，未登記 SSH、執行網絡操作、建置、取消、重啟、傳送、下載、操作介面、測試或擷取畫面。四種目標、持續預留復原及串流下載全部未驗收。目標由原生文件選擇，唔係遠端主機探索；傳輸有界但唔自動續傳，WSL 來源及外部樹傳送仍不支援。
