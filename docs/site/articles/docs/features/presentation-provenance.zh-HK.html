展示內容嘅來源證明

English · 文章目錄

文件建置會分開記錄來源身分、來源更新時間、製作時間同視覺驗收。佢哋係唔同事件，唔可以互相代替。

首頁顯示嘅資料

文件頁首顯示套件版本、縮短咗嘅來源提交、確切輸入快照摘要、建置時間，同最近一次已提交輸入變更時間。如果輸入已修改，來源更新時間會明確顯示無法取得，但輸入快照仍可識別實際來源位元組。建置時間會標示為建置時間，唔會當成來源修改或畫面擷取日期。完整值保留喺 site/build-info.json。

本機字型清單

兩個根目錄建置目標都會取得鎖定檔指定版本：@fontsource-variable/roboto@5.2.9 同 @fontsource-variable/noto-sans-hk@5.3.1。Roboto 提供所選套件樣式表內全部正常同斜體字重子集；Noto Sans HK 提供粵語後備所需全部正常字重子集。匯入會保留原有字重同 Unicode 範圍宣告。只發佈樣式表引用嘅 WOFF2 檔，唔會一併帶入重複套件版本或來源樹。依賴透過正常建置啟動流程下載，新增字型二進位檔唔會放入來源控制。

桌面同文件字型堆疊先選 Roboto Variable 同 Noto Sans HK Variable，之後沿用既有系統後備字型。桌面字型係可尋址輸出檔，唔係行內資料。製作掛鈎複製每個套件完整授權，記錄授權雜湊、必要來源樣式表同子集雜湊，並要求每個來源字型雜湊都匹配產生嘅本機字型檔。缺少子集或安裝版本錯誤會停止製作。assets/fonts-manifest.json 記錄實際位元組數、字型總輸出大小同來源身分。文件頁尾連到清單；桌面輸出喺 dist/assets 保留自己嘅清單同授權。

清單係製作中繼資料，唔係正確顯示證據。二進位變化軸、字形解讀、每個必要字重同 CJK 後備仍未驗證。此選擇冇匯入 Noto Sans HK 斜體，唔聲稱有原生斜體字面。安裝包壓縮同最終大小需要真實製作結果。瀏覽器字型檢查同離線顯示仍待驗證。

分享連結

靜態頁面標題同描述會喺輸出 HTML 前作跳脫處理。Open Graph 同摘要卡片中繼資料使用內置項目圖示，替代文字會講明係圖示，唔係畫面擷取。訪客筆記、匯入用語、主機路徑同私人工作區狀態都唔會提供呢啲中繼資料。冇新增分析服務或外部預覽服務。Referrer policy 有明確設定。逐篇文章嘅 canonical URL 中繼資料仍係另一項未完成能力。

歷史圖庫同錄影

每張保留圖庫卡都清楚標示為歷史，唔證明目前建置外觀或互動。穩定擷取識別碼、原始檔名、映像位元組、來源修訂、雜湊同已記錄時間全部保留。清單提供 presentationStatus: historical、目前建置擷取不可用狀態，同空白錄影清單。空白錄影清單只代表冇已發佈錄影，唔代表成功執行過錄影。

靜態圖片唔能夠證明轉場時間、鍵盤操作、進度保留或完整流程錄影。來源時間同收據檢查時間唔可以代替擷取時間。當時嘅目前畫面同定時錄影仍待處理。早期原件同來源證明保留喺證據存檔。

交付界線

此文記錄嘅原實作只屬來源工作。該實作範圍冇執行測試、審查、靜態分析、瀏覽器互動、畫面擷取、字型顯示檢查或部署驗證。製作必須喺固定候選來源使用根目錄 build.bat --target documentation /s。製作成功只證明輸出已產生；目前瀏覽器行為、中繼資料交付、字型選擇同擷取驗收需要另外證據。
