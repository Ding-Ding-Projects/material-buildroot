English · 文件索引

Material Buildroot 係 Windows 桌面工作區，提供項目、配置同執行流程。先讀新手指南，再跟住開始使用。

已有普通未簽署 Squirrel.Windows 發佈。Build 233.1，來源 21bf4ad4c6e1fb19a8a48fae57cdca6d63777c6a，已有正常安裝後啟動、About 導覽同返回工作區嘅驗證，詳見已記錄安裝版本界線。之後 Build 234.1 已發佈，但此處未證明佢已安裝。目前 ISO 介面候選唔可以因此當成已包含喺獲驗收嘅安裝版本。

已有真實 WSL/Docker 檢查同完整非 root BIOS GRUB2 ISO 製作記錄。未修改嘅 12,357,632 位元組映像喺記錄所列 QEMU 10.0.13/Cirrus/RTL8139 組合啟動，完成主控台、暫存檔、DHCP、內部閘道同關機檢查。請讀製作證據同有限範圍啟動證據。其他硬件、韌體、持久儲存、互聯網連線同候選原生發佈驗收，都係獨立要求。目前交接同路線圖保留未完成狀態。
