# 桌面工作區

應用程式直接開啟可編輯嘅工作區。首次設定精靈會記錄預定 Linux 執行環境、建立真實儲存嘅專案計劃，同埋檢視外觀。上一步、略過同繼續設定會保留進度；略過唔等於完成。設定精靈唔會聲稱已安裝或驗證執行環境。

## 計劃同復原

計劃包含名稱、預定執行環境、輸出、狀態同備註。套用同放棄控制待儲存變更；離開未儲存嘅計劃前需要明確選擇。計劃、主題同設定進度使用具修訂檢查嘅原子儲存。衝突或未知結果會保留草稿；結果未知時，重新啟動並檢視儲存內容之前唔可以繼續修改。

快照保留已套用內容。還原同匯入會經檢視後建立新修訂。JSON 匯出唔包含權限憑證或受保護記錄。開始下載只代表已發出要求，唔代表作業系統已成功儲存檔案。活動記錄會持久保留。

## 專案操作

原生資料夾選擇器授權存取工作區、現有 Buildroot 來源同獨立輸出目錄。接入前需要確認信任來源程式碼。重新啟動後會保留專案身份，但唔會自動恢復檔案權限；重新揀選相同目錄並確認來源，先可以重新連接相關工作。

執行環境探索會檢查 WSL 發行版同 Docker。建置只接受固定目標，並使用非 root Linux 環境。Docker 映像須已存在並以摘要固定版本。缺少工具、唔支援嘅路徑同先決條件會明確回報。建置記錄保留實際狀態、分頁記錄同結果；取消要求唔等於已停止。

設定介面提供按類型編輯、修訂衝突、預設設定同復原。選擇可信 Python 後，可以執行隨附並固定版本嘅 Kconfig 讀取器，檢視選單、類型、相依關係、選擇、範圍同說明。套用會透過已授權環境執行 `olddefconfig`；特定來源嘅相容性仍需要獨立驗證。

輸出檢視提供摘要、中繼資料同有界文字預覽。虛擬機控制只操作由應用程式管理嘅 VirtualBox 或 VMware 客體。關機要求唔代表已停止，須重新整理實際狀態。本機 Ollama 助理只傳送明確撰寫嘅訊息，唔會自動附加專案檔案或執行建議。更新下載會驗證位元組，但唔會自動安裝。

## 介面同驗證

介面使用已註冊嘅 Material Web 控制項、本機字型、淺色／深色／系統主題，以及英文、香港粵語同雙語。導覽同對話框管理鍵盤焦點；動效遵從減少動態效果偏好。正規表示式工作台使用隔離背景執行緒、有界配對、擷取群組、替換預覽同測試範例；逾時或引擎限制會明確顯示。

Linux Chromium 測試會操作真實介面；工作區持久性測試會使用實際本機儲存服務。呢啲結果唔代表 Windows IPC、安裝、原生縮放、WSL、Docker 或客體已通過驗證。按擁有人要求，Windows 執行測試暫緩。完整路線圖同各介面嘅驗收要求仍然保留。
