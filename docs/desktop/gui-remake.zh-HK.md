# 使用重新設計嘅桌面工作區

新介面根據主分支版本 `9223534b5cfd4f2d6daa62bff9670411931f0f3d` 嘅八個[設計參考畫面](../../design/IMPLEMENTATION_HANDOFF.md)重整，舊附件已經唔再用作實作依據。新版 Expressive 介面仍在實作同驗證，保留現有主機 API、專案識別、來源批准、檔案存取同執行檢查。

## 建立同繼續映像專案

映像目錄提供獨立搜尋、正規表達式工作台、資料夾存取同已開啟工作區篩選。選取同匯出目錄唔會刪除專案。開啟專案仍然要透過主機更新真正嘅資料夾授權。五階段建立精靈保留草稿同簡易、進階操作。

## 睇清楚目前工作

標題列顯示真正版本同來源資料。導覽列提供映像、建置、工具、說明同設定。新設定用左側分頁欄，已有嘅分頁位置會保留。工具分頁繼續屬於原本專案，關閉導覽唔會刪除專案或者偷偷捨棄草稿。

## 建置、工具同離線說明

建置畫面分開顯示佇列、准入狀態同輸出。輸出有獨立搜尋、跟隨同滑鼠、鍵盤調整高度。工具側欄保留現有轉換、佇列、PDF、編輯器同相關工作。離線說明提供主題、文章、目錄同上一頁、下一頁記錄。未知數值同未可用功能會清楚交代，唔會借示例扮成功。

## 設定同安全操作

設定按工作分類，保留真正語言、外觀、排程、專注、個人用語、備份同更新控制。每個搜尋欄各自管理正規表達式狀態。指令面板執行前重新確認目前動作權限；通知檢閱保留實際選取記錄；破壞性操作保留授權步驟、有效期同緊急取消。

## 驗證範圍

新版設計畫面同歷史參考圖片唔代表新版執行證據，較早嘅執行結果亦唔能夠證明同最新設計一致。來源檢查、瀏覽器測試、真正桌面操作、安裝同發佈分開記錄喺 [HANDOFF.md](../../HANDOFF.md)。正常客戶區為 1440 乘 960，最小為 960 乘 640；保留英文、廣東話、雙語、深淺主題、鍵盤操作同減少動態效果。
