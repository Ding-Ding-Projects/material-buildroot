# 獨立容器作業系統

Images 工作區新增引導流程，由 Linux x86-64 容器映像、映像封存或支援嘅 Compose 專案製作獨立 BIOS ISO。WSL 負責建置；成品包含自己嘅 Linux 核心、根檔案系統同容器執行環境。製作成功唔代表已通過開機驗證。

## 實際操作

選擇來源同非 root WSL 2 環境，設定 kiosk 或主控台、獨立持久資料磁碟或暫存資料，預覽後再確認建置。建置、取消、狀態、開機驗證同匯出都由執行中嘅桌面程式操作。成品存入目前使用者嘅 Downloads，唔覆寫已有檔案。開機服務唔會自行格式化磁碟。

## 個人用語同通道

可選擇將完整驗證嘅個人用語 JSON 加入私人映像；檔案唔會寫入日誌或公開證明，只喺通過驗證嘅私人介面生效。第三方程式需要自己支援相容嘅載入功能。清除後還原原有文字。

通道可選關閉、Cloudflare 臨時通道或自訂網域嘅具名通道。認證資料只喺開機後透過受保護介面輸入，唔加入 ISO。必須實測服務同端點先可稱為可連線。臨時通道網址會變，而且唔支援 Server-Sent Events。

## 驗證狀態

目前仍在實作。未宣稱完成目前版本嘅 WSL 建置、ISO、獨立開機、kiosk、區域網絡、通道、持久資料、Job 2027 或自訂 Home Assistant 驗收。各項均需要獨立、綁定來源嘅執行證明。

## 來源相容性與執行批准

來源準備只會讀取所選提交入面一小組固定已追蹤檔案，判斷可用建置配方。來源網址必須係冇內嵌憑證嘅 GitHub 網址，只會留喺本機選取記錄，唔會隨程式附送維護者專用網址清單。套件名稱或者檔案結構吻合，只代表相容性線索，唔代表密碼學信任或者執行許可。

原生來源選取權限、鎖定主來源同配對來源版本、冇已追蹤改動，以及明確執行批准仍然必須保留。介面唔可以自行選擇配方或者提供命令。未追蹤部署檔案同現有資料唔會加入隔離來源快照。
