# Ollama 工作區

[English](ollama-workspace.md) · [桌面文件](README.md)

Local assistant 工作區將受管理執行環境安裝同修復、官方目錄瀏覽、本機模型偵測、硬件證據、持久模型下載同串流本機對話放喺同一流程。

先選目錄標籤或已安裝模型。選目錄唔會開始下載。要明確儲存下載工作，檢視共用工具佇列，再開始執行。佇列亦會執行其他已排入工具工作。重新整理已儲存下載可查看狀態、取消自己擁有嘅下載，或重新排入失敗、已取消或中斷項目。復原會將遺留嘅執行中記錄標記中斷。Ollama 決定邊啲已下載 blob 可以重用；復原唔會刪除已安裝模型。

受管理安裝係另一個需要檢視嘅操作，優先用已驗證內置或快取內容，亦可選官方取得途徑。啟動或停止受管理接聽服務同安裝分開。既有控制器會保留現有安裝同模型目錄。

對話必須選已偵測到嘅已安裝模型。主機建立一個有界限嘅記憶體生成工作階段，從固定 loopback Ollama 端點串流，再透過已驗證輪詢操作提供有限回覆區塊。Cancel 操作該階段嘅 AbortController。Reconnect 只重試回覆輪詢，唔會重送提示。離開元件會要求取消。消費端會忘記已完成階段；遺留終止階段五分鐘後到期。最多保留八個階段，同時只可有一個生成。

提示同回覆唔會寫入持久工具佇列或程式記錄。明確選 **Save local snapshot** 先會將有限記錄寫入目前帳戶嘅本機程式資料。Open 還原已儲存對話同模型；Delete saved copy 要第二次確認，只刪該副本。清除對話只移除顯示中嘅記憶體內容，唔會刪已儲存副本。儲存庫最多接納 100 個快照，驗證訊息界限、拒絕連結目錄同記錄，並將寫入串行處理。佢冇額外加密，儲存前可見提示會講明。

取消或失敗嘅部分回覆會保持明確部分狀態，唔會當成完整助理回合附加。切換模型會清除對話。項目檔案同記錄唔會自動附加。

## 限制同驗證

官方目錄係觀察到嘅分頁快照，唔聲稱完整或原子總清單。確切大小、授權、能力同硬件適用證據可以保持未知。原流程冇加上原生 GPU 探測。Ollama 下載期限為 60 分鐘，對話為 10 分鐘，都保留所屬取消功能。其他有界限工具要求沿用 120 秒預設。主機將期限限制喺一秒至 60 分鐘，渲染器唔可以任意指定逾時。到期下載可明確重新排入，冇自動重試或成功續傳聲稱。

實作同套件編譯唔證明執行驗收。原快交付變更冇執行測試、執行環境操作、模型下載、安裝、視覺檢查或畫面擷取。既有歷史圖片唔係新工作區畫面。原生安裝復原、取消下載、串流取消、導覽、無障礙同重新啟動行為仍未驗證。

## 原生顯示配接器觀察

明確要求硬件證據時，會透過作業系統 PowerShell 執行固定內置 `ollama-hardware.ps1`，隱藏且非互動。只查詢 `Win32_VideoController`，CIM 限兩秒、主機期限四秒、輸出上限 32 KiB，最多 16 筆記錄。呼叫者取消只會終止所屬查詢程序。渲染器唔提供執行檔、腳本、查詢或指令參數。唔會安裝或啟動引擎或驅動程式。

面板顯示配接器名稱、廠商、驅動版本同原始 `AdapterRAM`。Microsoft 文件將 `AdapterRAM` 定義為唯讀無號 32-bit 位元組數，見[官方 Win32_VideoController 文件](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-videocontroller)。清單刻意將可用 VRAM 同後端支援保持未知，唔會將原始值用於適用性計算。偵測到配接器唔會令只支援 CPU 嘅套件變成支援 GPU。不支援主機、查詢失敗、格式錯誤同逾時都保留明確不可用結果。此來源路線喺原變更任務冇執行或取得執行驗證。
