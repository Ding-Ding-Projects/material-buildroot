# 簡易 ISO 板卡預設設定

空白或預設 32 位元專案可能未有 BIOS ISO 組合所需嘅處理器同 Linux 核心。簡易 ISO 嘅「需要電腦起點？」部分會列出來源實際提供嘅起點，毋須手動研究設定符號。

## 選擇來源實際提供嘅設定

1. 接入可信來源同獨立輸出目錄，再選擇支援嘅執行環境。
2. 按「核對來源執行權限」，閱讀確切範圍。只有信任來源時，先勾選同意並按「批准此範圍」。
3. 按「尋找來源電腦預設設定」。主機會讀取目前來源清單，傳回綁定修訂嘅識別資料。指南只提供主 Buildroot 來源中符合名稱嘅項目，唔會虛構項目或用外部樹同名設定取代。
4. 如來源有提供，優先選取 `pc_x86_64_bios_defconfig`，即來源嘅 BIOS 電腦範例。`qemu_x86_64_defconfig` 係另一個 QEMU 模擬機器範例。此 BIOS ISO 流程唔會建議只用 EFI 嘅設定。

以上名稱只識別來源範例，唔保證所有硬件適用。來源決定核心、套件、韌體同建置後動作，亦可能產生磁碟映像。清單有此項目，唔代表實際設定已驗證、ISO 已建置或可以開機。

## 核對取代範圍

指南列出確切預設設定名稱、來源目錄同將被取代嘅輸出設定。套用會取代現有套件同核心選擇，但唔會編輯來源預設檔案。

勾選「以所選電腦預設設定取代此輸出設定」，再按「套用此電腦起點」。瀏覽或選取本身唔會套用。改選項目會清除同意；重新讀取清單、更換專案或外部設定變更亦會令先前選取同同意失效。

現有設定服務會將先前設定保留喺有數量限制嘅工作階段復原記錄，協調失敗時會還原。想獨立保留兩套設定，請套用前選擇另一個輸出目錄。復原只係工作階段恢復機制，唔係持久備份，亦唔授權覆寫其他輸出。

要復原已完成嘅取代，請先為更改後設定核對權限，再喺設定編輯器按「檢視設定」，然後「排隊復原」，並檢視傳回結果。復原會再次改變範圍，返回 ISO 指南繼續前須重新核對權限。回覆遺失唔代表設定冇變。

## 套用後繼續

指南會核對傳回嘅實際值有冇啟用 `BR2_x86_64` 同 `BR2_LINUX_KERNEL`。缺少所需值時仍屬未完成。單單套用板卡預設設定唔會啟用 ISO 建置。

設定變更會令先前權限範圍失效。請重新核對來源執行權限，再按原有步驟檢查同設定 ISO 組合。每次批准都須明確操作；套用預設設定唔會自動授權、套用 ISO 組合或開始建置。

## 未能使用或過時結果

如果兩個已識別來源名稱都不存在，指南會明確顯示未發現支援起點。進階設定同現有完整預設設定清單仍可使用，唔會改用其他架構、外部設定或虛構通用電腦設定。

權限過期、清單修訂改變、執行環境缺少或協調失敗，都會保持未確認。請重新讀取清單並核對權限後再試。專案或設定改變後先抵達嘅舊回覆會被忽略，唔會自動無限重試。

繪製器測試只證明選取、同意、要求綁定同過時回覆處理。真正 Buildroot 協調、原生執行環境、ISO 製作同開機須各自驗證。
