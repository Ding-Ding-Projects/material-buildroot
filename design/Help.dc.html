Create your first image

10 min read · works offline · updated 28 Oct 2026

An image is a complete, bootable Linux system built from your choices. The guide walks you through five stages, and you can switch between Easy and Advanced without losing your draft.

1. Choose a purpose

Pick what the device should do. The purpose sets sensible defaults for packages and size.

lightbulb

Every control in the guide has an info button that opens the matching step in this article.

2. Pick a target

Choose a board or a virtual machine. Board presets fill in the architecture and boot method.

3. Configure

Easy mode shows the size budget and the packages most images need. Advanced opens the full configuration with search and the regex builder. Both edit the same draft.

4. Build and verify

Builds run in WSL 2 or Docker as your normal user, never as root. When a build finishes, the output hash is recorded and the image appears in Images, ready to flash.
