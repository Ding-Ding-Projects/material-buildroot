# Roadmap

## Buildroot workflows

- [ ] Windows desktop shell and secure IPC.
- [ ] WSL 2 discovery, prerequisites, project execution and cancellation.
- [ ] Docker discovery, isolated non-root builds and lifecycle controls.
- [ ] Full Kconfig tree, typed controls, choices, dependencies, help and reconciliation.
- [ ] Defconfigs, external trees, separate output directories and build targets.
- [ ] Streaming logs, build history, cancellation and image inspection/export.

## Shared application features

- [ ] English, Cantonese and bilingual modes with independent humor settings.
- [ ] Tabs, search, anchored regex builder, command palette and notifications.
- [ ] Appearance, accessibility, element controls, locks and support tickets.
- [ ] History, exports, local snapshots, file conversion and documentation browser.
- [ ] Ollama suite and one-click managed runtime recovery.
- [ ] Minecraft server creator and manager for all four required targets.

## Delivery evidence

- [ ] Source-bound real desktop captures and language/theme/scale matrix.
- [ ] Fresh Windows bootstrap, unsigned Squirrel installer and update validation.
- [ ] Public repository, documentation website, wiki and live download verification.
